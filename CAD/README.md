# CAD y planos de fabricación

Esta carpeta contiene los archivos asociados al diseño mecánico y fabricación de las cajas utilizadas para ensamblar el prototipo.

Se incluyen los planos de las dos cajas diseñadas para ser cortadas mediante láser y posteriormente ensambladas. Estas piezas fueron utilizadas para organizar y contener los componentes principales del sistema, permitiendo una distribución más ordenada del hardware y facilitando su montaje.

Los archivos de esta carpeta corresponden a la versión utilizada durante la fabricación del prototipo Alpha y sirven como respaldo del diseño mecánico desarrollado para el proyecto.
