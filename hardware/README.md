# Hardware

Esta carpeta contiene la documentación asociada al hardware del prototipo.

Se incluyen el esquemático eléctrico actualizado, el diagrama general de funcionamiento y la lista de materiales utilizada para construir el sistema.

El esquemático muestra las conexiones principales entre las piezas electrónicas, de alimentación, el sistema hidráulico, la compresa, el encapsulado, y el software.

La lista de materiales incluye los componentes utilizados, sus cantidades, especificaciones principales y costos aproximados.
